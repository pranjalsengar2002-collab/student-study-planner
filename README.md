# student-study-planner

A simple, elegant, and user-friendly **Student Study Planner** designed to help students organize their daily study tasks, track progress, and stay focused.

## ✨ Features

- 📋 Add daily study tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📊 Automatic progress tracking
- 📈 Completion percentage
- 🔥 Daily study streak
- ⏱️ 25-minute study timer
- 📚 Subject-wise study section
- 💡 Study tips
- 💾 Tasks saved in the browser
- 📱 Responsive design
- ⚡ Lightweight and fast

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
